>> REGISTRO DE FINTECH EN AUTHORIZATION SERVER (realm sfa-mtls-poc)
Perfil TPP mTLS/X509: autenticacion en /token via certificado de transporte (tls_client_auth).
Incluye client_credentials para M2M sin client_assertion ni private_key_jwt.

curl --location 'http://127.0.0.1:8080/realms/sfa-mtls-poc/clients-registrations/openid-connect' \
--header 'Content-Type: application/json' \
--header 'X-Software-Statement: $SSA' \
--data '{
    "grant_types": ["authorization_code", "refresh_token", "client_credentials"],
    "response_types": ["code"],
    "token_endpoint_auth_method": "tls_client_auth",
    "tls_client_auth_subject_dn": "CN=LIDER-BCI,O=LIDER-BCI,C=CL",
    "tls_client_certificate_bound_access_tokens": true,
    "redirect_uris": ["http://localhost:3000/callback"],
    "scope": "accounts:read"
  }'

El tls_client_auth_subject_dn debe coincidir con el Subject de transport.crt:
  openssl x509 -in client-jwks/LIDER-BCI/transport.crt -noout -subject

>> TOKEN client_credentials CON CERTIFICADO X509 (sin client_assertion)
Requiere que el endpoint /token exija mTLS y Keycloak valide el certificado contra x509.subjectdn.
En produccion suele haber un reverse proxy (Envoy/Nginx) que termina TLS y reenvia el certificado.

curl --cert client-jwks/LIDER-BCI/transport.crt \
     --key client-jwks/LIDER-BCI/transport.key \
     --cacert registro_participantes/ca/root-ca.crt \
     --location 'https://<host-mtls>/realms/sfa-mtls-poc/protocol/openid-connect/token' \
     --header 'Content-Type: application/x-www-form-urlencoded' \
     --data-urlencode 'grant_type=client_credentials' \
     --data-urlencode 'client_id=LIDER-BCI' \
     --data-urlencode 'scope=accounts:read'

Notas:
- No se envia client_assertion ni client_secret: la autenticacion es el certificado TLS.
- tls_client_certificate_bound_access_tokens=true ata el access token al certificado presentado.
- Keycloak en docker-compose actual (HTTP :8080) no termina mTLS; esta llamada aplica cuando
  el AS/Gateway exponga HTTPS con clientAuth y confie en registro_participantes/ca/root-ca.crt.
